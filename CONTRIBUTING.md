# Как контрибьютить

Проект личный и опенсорсный: PR приветствуются, но планка простая — **сборка, тесты,
clippy и fmt должны быть зелёными**, а изменения — небольшими и понятными.

## Требования

- Rust 1.75+ (`rustup default stable`).
- Никаких внешних сервисов для сборки: `cargo` и всё.

## Команды

```bash
cargo fmt --all -- --check          # форматирование
cargo clippy --workspace --all-targets -- -D warnings
cargo test --workspace              # юнит + интеграционные + CLI
cargo run -- demo                   # живой сценарий ядра
cargo run -- host --port 7878       # поднять комнату
cargo run -- join 127.0.0.1:7878 --code <код>
```

## Что проверяется на CI

1. `cargo fmt --check`
2. `cargo clippy -- -D warnings`
3. `cargo test --workspace` (Windows и Linux)
4. `cargo run -- demo` (сценарий целиком)

## Стиль кода

- Форматирование — `cargo fmt`, без споров.
- В публичных API — `#[must_use]` и doc-комментарии `///` (на русском).
- Никаких `unwrap()`/`expect()` в библиотечном коде, кроме доказанных инвариантов
  (тогда — с комментарием). В тестах можно.
- Ошибки: `thiserror`-стиля `enum` в библиотеках, сообщения — по-русски и понятные.
- Никаких глобальных мутабельных состояний.
- `#![forbid(unsafe_code)]` — сохраняем.

## Где что лежит

| Хочу… | Иду в |
|---|---|
| добавить правило/формулу | `crates/vtt-core/src/rules.rs` |
| добавить тип токена/персонажа | `crates/vtt-core/src/entities.rs` |
| добавить интент | `vtt-proto` → `vtt-server` → `vtt-app/common.rs` |
| добавить команду CLI | `crates/vtt-app/src/common.rs` |
| транспорт | `crates/vtt-net/` |
| документацию | `docs/` |

Подробнее: [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).

## Правила PR

1. Один PR — одна мысль. Не смешивайте рефакторинг и новую функцию.
2. Новое поведение — с тестом. Баг — сначала тест, потом фикс.
3. Обновляйте доки, если меняете поведение/формат/интенты.
4. Меняете `PROTOCOL_VERSION` — опишите миграцию в описании PR.
5. Контент — по [CONTENT-LICENSING.md](docs/CONTENT-LICENSING.md). Без этого PR
   с контентом не принимается.

## Коммиты

Свободная форма, но полезно:
`core: добавлен расчёт нагрузки`, `net: реконнект клиента`, `docs: ADR-009`.

## Если не знаете, с чего начать

Ищите в [ROADMAP](docs/ROADMAP.md) пункты `[ ]` — они упорядочены так, что начало
списка важнее конца. Хорошие первые задачи: статблоки монстров (M1), тесты на
краевые случаи правил, документация.

## Общение

Пишите по-русски или по-английски. Главное правило: обсуждаем код, а не людей.
