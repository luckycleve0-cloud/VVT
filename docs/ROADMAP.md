# Roadmap

Ориентир — [план продукта](04-план-и-оценки.md). Здесь — конкретные шаги по коду,
в порядке, в котором их имеет смысл делать.

Обозначения: `[ ]` не начато, `[x]` готово, `(~)` прототип/частично.

## M0 — Ядро (готово, v0.1)

- [x] Домен: сцены, токены, персонажи, эффекты, условия
- [x] Правила 5e: модификаторы, спасброски, навыки, атаки, урон
- [x] Дайсы: парсер, keep/drop, преимущество/помеха, криты
- [x] Сетка: квадрат, гекс, снап, измерения
- [x] Стены/двери/окна, линия видимости, ручной туман, шаблоны AoE
- [x] Права и роли
- [x] Авторитарный сервер + протокол + снапшоты
- [x] TCP-комната, клиент, CLI (`demo`, `host`, `join`, `info`)
- [x] Сохранение кампании в JSON
- [x] Тесты, clippy/fmt, CI

## M1 — «Играбельно в консоли» (готово, v0.2)

- [x] Паки контента: JSON с манифестом, `ContentRegistry`, поиск, `--pack`
- [x] Токен из компендиума (`spawn <монстр> <x> <y>` и `Intent::SpawnMonster`)
- [x] Отдых: короткий/длинный, лечение до максимума, сброс смертей
- [x] Спасброски от смерти: счётчики, натуральные 20/1, «мёртв», стабилизация
- [x] Концентрация: установка/снятие, СЛ = max(10, урон/2) при получении урона
- [x] Хендауты: `handout <заголовок> | <текст>`, история в кампании
- [x] Журнал сессии: `session.log` рядом с кампанией
- [x] Переподключение: `leave` сохраняет сессию, `--resume <id>` возвращает владение
- [ ] Ресурсы и отдых по хит-дайсам (сейчас длинный отдых лечит полностью)
- [ ] Эффекты с длительностью тикают по раундам автоматически
- [ ] Спасброски от смерти на листе персонажа (сейчас — на токене)

**Готово, когда:** группа может вести бой со смертями, отдыхом и концентрацией
без бумаги. Проверяется в `cargo run -- demo`.

## M2 — Окно и карта (готово, v0.2, прототип)

- [x] Окно 1280×800, шрифт с кириллицей (системный)
- [x] Камера: панорама, зум к курсору, «показать всю карту»
- [x] Карта картинкой (png/jpg), сетка с отсечением по видимой области
- [x] Токены: размер, цвет, имя, HP-бар, концентрация, «мёртв», скрытость
- [x] Перетаскивание токенов с привязкой к сетке (через `Intent`)
- [x] Линейка в футах, шаблоны-заготовки, пинги с анимацией
- [x] Ручной туман (круг), очистка тумана
- [x] Стены и двери (отрисовка)
- [x] HUD: кампания, сцена, инструмент, журнал, FPS
- [x] Ядро игры в том же процессе (одиночный режим)
- (~) Спрайты токенов вместо кружков — нужна загрузка ассетов
- [ ] egui-панели: лист персонажа, трекер инициативы, чат
- [ ] Шаблоны AoE мышью (конус/линия/круг с направлением)

## M3 — Лист персонажа (готово, v0.3) и компендиум в UI

Сделано по правилам SCP (файл `SCP_Rules_Fixed.docx`), см. [RULESET-SCP.md](RULESET-SCP.md):

- [x] Модель листа: 10 характеристик, 42 навыка, 9 классов, уровни допуска
- [x] Производные: физическое/психическое здоровье, движение, удары, инициатива
- [x] Броски навыков и характеристик на сервере (`CheckResult`, d20 + бонусы)
- [x] Психоз d10 и душевный подъём d4
- [x] Опыт с бонусом ИНТ, повышение характеристик за 50/100 опыта
- [x] Проверка корректности стартового листа (70/84 очка, лимиты)
- [x] Интерактивная панель в окне: здоровье ±, характеристики ±, навыки ±, броски, СЛ, психоз, XP, токен
- [x] Токен привязывается к листу (`Token::character`), HP-бар из листа
- [x] CLI: `newchar`, `check`, `attrcheck`, `sanity`, `xp`, `levelup`
- [x] **Окно создания персонажа**: имя, класс, допуск, распределение очков характеристик и навыков с бюджетами
- [x] **Список персонажей** в окне (аналог «Characters» в Roll20) и кнопка «+ Персонаж»
- [x] **Круговые токены из картинок**: выбор файла встроенным проводником, обрезка в круг на CPU, 4 рамки и 8 цветов
- [x] **Мультивыделение** (Ctrl+клик, рамка), групповое перетаскивание и удаление
- [x] **Размер токена** (`[`/`]`), **границы карты** перетаскиванием края (ГМ), зум шагом 10% (10–400%)
- [x] **Панель токена по кнопке**: размер, прозрачность (шаг 10%), скрытие от игроков
- [x] **Чат в окне** (GM ↔ игроки) и **комната ГМа по TCP** с кодом и адресом
- [x] **Роли и кик**: список участников, выдача роли (игрок/со-ГМ/зритель), кик
- [x] **Настройки комнаты и поля** в окне: сетка, клетка, футы, карта, туман
- [x] **Адаптивное окно**: виртуальный экран 1440×860, letterbox при любом размере
- [x] **Картинки PNG/JPEG/BMP/WebP** (JPEG раньше не открывался — `macroquad` умеет только PNG)
- [ ] Лист D&D 5e в окне (модель и расчёты в `vtt-core::entities` уже есть)
- [ ] Журнал: статьи, папки, права видимости в UI
- [ ] Компендиум в окне: поиск и перетаскивание
- [ ] Оружие/броня как предметы с ОС и уроном (сейчас — вручную)
- [ ] Психоз как активный эффект с длительностью (сейчас — результат в журнале)

## M4 — Свет, стены, видимость (готово частично, v0.3)

## Не делаем (сознательно)

| Что | Почему |
|---|---|
| Полная автоматика боевых цепочек | годы работы, ломается на домашних правилах |
| Мультисистемность в ядре | 5e даёт основную аудиторию; системы — плагинами позже |
| 3D-стол (TaleSpire-стиль) | другой продукт и другой рендер |
| Видеочат | Discord лучше, это не наша задача |
| Свой маркетплейс | юридические и модерационные издержки |
| Скрипты пользователей в ядре | безопасность и поддержка; плагины — песочница WASM |

## Как выбирать следующую задачу

1. Сначала то, без чего нельзя играть (M3–M4).
2. Потом то, что снимает боль конкурентов (M5).
3. Фичи «вау» (M7) — когда есть база и обратная связь.
