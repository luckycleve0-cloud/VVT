# BRIEF — исследование для проекта «единый VTT на Rust»

## Что делает заказчик
Хочет собрать **одно нативное десктоп-приложение (Rust, Windows-first)** — виртуальный
стол для D&D 5e / 5.5e (2024), объединяющее фишки существующих VTT
(Roll20, Owlbear Rodeo, Foundry VTT, Fantasy Grounds и др.), потому что ни в одном
нет всего сразу и неудобно переключаться между сервисами.

Ключевое требование по инфраструктуре: **ГМ выступает хостом**. Приложение ГМа служит
сервером комнаты, игроки подключаются к нему напрямую (по типу Hamachi / Radmin VPN /
ZeroTier), все токены, карты, ассеты передаются с ПК ГМа. Платных серверов быть не должно
(максимум — бесплатный/дешёвый fallback-релей).

## Что нужно от исследования
Только проверяемые факты + ссылки. Никаких выдуманных функций. Если факт
непроверяем или устарел — так и пиши («не подтверждено», «по состоянию на 2025»).
Опирайся на официальные сайты, доки, changelog, store-страницы, обзоры 2025–2026.

Формат: Markdown на русском, плотные таблицы, без воды. Термины VTT оставляй
на английском в скобках при первом упоминании.

## Общий контекст анализа (для всех)
Интересует прежде всего D&D 5e / 5.5e (2024), но помечай, если фича
системо-независимая. Отдельно помечай: бесплатно / подписка / единоразовая покупка.
